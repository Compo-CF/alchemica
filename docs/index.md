# Alchemica: Roguelite

> Fill the cauldron. Spark the reactions. Complete the Great Work.

Alchemica is an alchemy roguelite card game for iPhone. Place ingredient cards on a 3x3 cauldron: neighbours react (Steam, Clay, Dust, Blaze), full lines of one element form Sigils, and both diagonals make the Philosopher's Cross. Build your run with Reagents, the Formula board and Tinctures, survive six Circles of Trials, and come back for a new Daily Brew every day.
